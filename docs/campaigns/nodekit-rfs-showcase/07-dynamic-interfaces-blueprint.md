Personalization that changes only the content inside a fixed interface is not very personal.

YC's Dynamic Software Interfaces request asks whether users can become their own forward-deployed engineers and reshape software around their actual jobs.

NodeKit's proposed wedge is a personal interface compiler.

User: the person doing the work.

Job: reshape an application around the outcome they are trying to accomplish.

Artifact: a versioned interface specification with a preview and behavioral diff.

What matters most is preserving the underlying application contract. A founder's email surface might become a prioritized decision queue while a student's becomes a calendar, but both still act on the same messages, permissions, policies, and recovery paths.

This is Blueprint 07/16, not a finished interface. The benchmark will compare a raw prompt with a NodeKit product contract, use a pinned frontend model, inspect full workflow and exception states, and publish blind preference results.

If you could completely reshape one application around your job, which application would you choose?
