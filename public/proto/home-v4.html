Yes. The upcoming MCP auth standard (Q3 2026) includes a scoped tool-use permissions model. It maps tool categories to OAuth 2.1 scopes, so servers can declare which tools require which permissions. This is separate from but compatible with the backwards-compatible transport layer Dario mentioned.
